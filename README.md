# Pairwise Ranker

**WIP - A Python learning project for ranking items through pairwise comparisons and statistical preference models.**

## Overview

Pairwise Ranker is an experimental Python project that aims to generate subjective rankings by asking the user to compare two items at a time.

Instead of assigning scores directly, users express their preferences through individual comparisons. These preferences will then be processed using statistical models to estimate an overall ranking.

The initial use case is ranking a personal collection of video games (Steam wishlist), although the project is intended to support other types of items.

## Planned Features

- Import items from text files.
- Remove duplicate entries while preserving their original order.
- Compare two items at a time.
- Support ties and equivalent preferences.
- Estimate rankings using statistical preference models.
- Save and resume comparison sessions.
- Export completed rankings.
- Track comparison progress and estimate remaining time.
